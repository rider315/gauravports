022026Solo build

Chills

Tailor your resume to any job, approve every change, then email the recruiter with it attached.

The resume is a LaTeX file and it stays the source of truth. The model may only rewrite the summary, skills and bullet points. Employers, dates and project headings are frozen, so it can't invent a job. Every edit is shown as a diff for approval and spliced into the exact byte range of its macro. An allow-list sanitizer runs last, because a job description is untrusted input and \input or \write18 would mean file or shell access at compile time.

Next.js · TypeScript · Postgres (Neon + Drizzle) · Claude & Gemini APIs · Zod · Nodemailer · Chrome extension

A trading engine that distrusts its own backtests.

Fourteen strategy modules feed an evaluation matrix. A five-gate risk manager sits between every signal and the market. Research runs on AWS Spot fleets, and a configuration only counts as an edge if it is profitable in all three independent test periods.
